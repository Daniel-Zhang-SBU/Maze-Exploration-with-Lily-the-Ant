# Maze-Exploration-with-Lily-the-Ant
Build a console-based maze game in C where Lily the Ant explores a maze, collects points, and tries to achieve the highest score before time runs out. The project must also demonstrate program organization through an Abstract Data Type (ADT), a stack-based Undo feature, and a queue-based shortest-path search
